AI coding assistants that speak the **Model Context Protocol (MCP)** can now read files, run terminal commands and call APIs on your behalf. That is powerful, and it changes the security question from "is the model's answer correct?" to "what can this agent *do* if it is wrong — or if someone tricks it?"

## The two failure modes that matter

**1. The agent does something destructive.** A model can misread an instruction, or follow instructions hidden inside a file, web page or dependency it was asked to read (indirect prompt injection). If the agent has a shell, "clean up the build folder" and "delete the repo" are one bad path away.

**2. The agent burns money.** Agents loop. A tool call that fails, retries and re-plans can run for hours against a paid API. OWASP files this under *unbounded consumption*: the cost is real even when nothing is "hacked".

## Controls, from strongest to weakest

| Control | What it stops | Bypass risk |
|---|---|---|
| Least privilege (only the tools and folders a task needs) | Most damage, by removing the capability | Low |
| Sandboxing (container, VM or throwaway workspace) | Damage to your real machine and secrets | Low |
| Human approval for writes, deletes, deploys and payments | Destructive actions slipping through | Low, if you actually read the request |
| Spend caps enforced by the API provider or a proxy | Runaway cost | Low |
| Allowlists of permitted commands | Unexpected commands | Medium |
| Blocklists / pattern matching | Known-bad strings | High — easy to rephrase or encode |

The pattern is clear: **controls that remove capability beat controls that try to recognise bad intent.** A model cannot delete a folder it was never given access to.

## A minimal policy gate: how AegisMCP works today

[AegisMCP](https://github.com/thekartikeyamishra/AegisMCP) is a small monorepo with an MCP server (stdio transport) and a Next.js dashboard. Its current server code is short enough to describe completely:

- It registers **one tool, `secure-execute`**, which takes a text payload.
- Each payload is checked against a **blocklist of three patterns**: `rm -rf`, `chmod 777` and the phrase "ignore previous instructions". A match returns a "SECURITY HALT" error.
- Each allowed call is charged a **flat notional cost** (USD 0.005, multiplied by a 1.30 markup) against a **daily budget ledger** (USD 5.00 by default) stored in a local JSON file. When the ledger is full, calls return "FINANCIAL HALT".

What that means in practice:

- It guards **only the calls an agent sends through its own tool.** It does not sit in front of your agent's other MCP servers or built-in tools, so it is not a transparent firewall for everything Claude Desktop or Cursor can do.
- The cost figure is a **fixed estimate per call**, not a measurement of real token usage.
- Three regex patterns are a **demonstration**, not coverage: `rm  -rf` with two spaces, a script file, or base64 would pass.

That makes it a good, readable starting point for learning how an MCP policy gate is wired — and a reminder of why the stronger controls above matter.

### Trying it locally

```bash
git clone https://github.com/thekartikeyamishra/AegisMCP.git
cd AegisMCP
npm install
npm run dev
```

Then register the server in Claude Desktop's `claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`; Windows: `%APPDATA%\Claude\claude_desktop_config.json`), pointing at the built CLI:

```json
{
  "mcpServers": {
    "AegisFirewall": {
      "command": "node",
      "args": ["/absolute/path/to/AegisMCP/packages/cli/dist/index.js"]
    }
  }
}
```

Restart the app after editing the file. Cursor and other MCP clients accept the same `command` + `args` pair in their MCP server settings.

## A sensible setup for real projects

1. **Start read-only.** Give the agent read access to the project folder only. Add write access per task.
2. **Never mount your home directory, SSH keys or `.env` files.** Use a dedicated workspace or container.
3. **Keep approvals on** for shell commands, file deletion, git push and anything that costs money.
4. **Set a hard monthly limit in your AI provider's billing console** — that limit holds even if every other layer fails.
5. **Log every tool call** so you can see what happened after the fact.
6. **Add pattern checks last**, as an extra tripwire, not as the wall.
